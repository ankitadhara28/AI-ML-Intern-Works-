# AI-ML-Intern-Works-
Two fundamental ML projects demonstrating classification and regression techniques.
🚀 Projects
1. Spam Mail Detector
Text classification system to identify spam emails using NLP and machine learning.
Tech Stack: Python, Scikit-learn, NLTK, Pandas
Dataset: SMS Spam Collection (UCI)
Models: Naive Bayes, Logistic Regression
Results: 98% accuracy, 97% F1-score
Key Features:

Text preprocessing (tokenization, stopword removal)
TF-IDF vectorization
Confusion matrix analysis

2. House Price Prediction
Regression model predicting residential property prices based on features like size, location, and bedrooms.
Tech Stack: Python, Scikit-learn, Pandas, Matplotlib
Dataset: Boston Housing Dataset
Models: Linear Regression, Ridge, Lasso
Results: R² = 0.86, RMSE = $4,680
Key Features:

Exploratory data analysis
Feature engineering and scaling
Multiple regression algorithms compared

📊 Skills Demonstrated

Data preprocessing and cleaning
Feature engineering (TF-IDF, normalization)
Classification & regression algorithms
Model evaluation (accuracy, precision, recall, MSE, R²)
Data visualization
